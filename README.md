## PC_results
This project was made to collect data about CPU, RAM and GPU usage, and build graphs with it. Later, you are able to save them and then open again.
## How to use

1) Install python
2) Run this command: ``git clone https://github.com/Sohar20/PC_results.git`` or, if you don't have git, download these files: `requirements.txt`, `main.py`, `gui_1.py`. If you want to look at the GUI with QtDesigner you can download `gui1.ui` as well.
3) Run in terminal this command: `pip install -r requirements.txt`
4) Run file `main.py`

When button *Start monitoring* or key combination *Alt+P" pressed*, the programm will start collecting data. When button *Stop monitoring* or key combination *Alt+S* is presed or when the timer expires, the program will stop collecting data. To display the graph click on *Display the graph* button. To save the graph press button *Save the graph*. To open a graph from `.pkl` file press *Open graph* button.

## And one more thing

Every branch of the project is a new version of it, so check out the branches to get the newest version of the project!
